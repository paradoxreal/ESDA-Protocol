ESDA Protocol

A local-first cryptography workbench. One Python file, standard library only, no network required. It runs 41 tests across seven doors and prints exactly what passed.

Research and teaching code. Not independently audited. Not constant-time. Do not use it to protect real funds or real keys.

Three human tools

Split-Key Vault

Door 1 · Shamir secret sharing

Split a secret into 5 shares so any 3 rebuild it and any 2 reveal nothing. Give shares to people you trust; no single person holds the whole thing.

Tamper-Proof Diary

Door 2 · SHA-256 hash chain

Each entry is chained to the last, so one changed byte is caught. Merkle proofs show a single entry is in the diary without sharing the rest. The on-disk version survives a crash mid-write.

Offline Brain

Door 5 · local AI check

An optional check for a local Ollama model on your own machine, so questions about your data never leave it. Skipped when it's off.

Run it

git clone https://github.com/paradoxreal/ESDA-Protocol
cd ESDA-Protocol
./run.sh

Optional: pip install cryptography coincurve turns on the cross-checks that compare ESDA's math against OpenSSL and libsecp256k1.

Honest boundaries

  • The wall is 2128. Nothing here breaks SHA-256, RSA-2048 or secp256k1, and nothing here claims to.
  • A hash chain is tamper-evident only when its head hash is stored somewhere an attacker can't reach.
  • This page has no accounts, no analytics and no cookies.
